# dao Rider Recruitment – demo

Statisk demo (testdata, ingen backend). Én HTML-fil pr. side – intet build, ingen eksterne afhængigheder ud over Google Fonts.

- `index.html` – guidet demo
- `fuld-demo.html` – fuld demo (Rider + Recruit)
- `entry.html` – dao Hire Entry: kun ansættelsesflowet (Ansøgning → AI-interview → HR-interview → prøveperiode → fuld ansættelse)

## Publicér med GitHub Pages
Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.
Adresse: `https://s0ftwareteamdk.github.io/recruitment/` (fuld demo: `.../recruitment/fuld-demo.html`).
